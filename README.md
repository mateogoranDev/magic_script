# 🛠️ Suite de Soporte Técnico Automatizado

Este repositorio contiene un ecosistema de herramientas para técnicos de soporte IT, diseñado para optimizar el diagnóstico y mantenimiento de estaciones de trabajo Windows.

## 📁 Estructura del Proyecto
- **01_Scripts**: Contiene el núcleo de automatización en PowerShell.
- **02_Documentacion**: Guías de procedimientos y bloques de actuación.
- **03_Herramientas_Extra**: Software portable de terceros para diagnóstico profundo.
- **Lanzador.bat**: Acceso directo para ejecución con privilegios de administrador.

## 🚀 Funcionalidades del Script
1. **Auditoría de Hardware**: CPU, RAM y estado de discos.
2. **Mantenimiento de Red**: Flush DNS y renovación de IP.
3. **Optimización de Sistema**: Limpieza de temporales y reinicio de cola de impresión.
4. **Reparación de Integridad**: Ejecución de SFC Scannow con reporte de logs.
5. **Energía**: Generación de informes de salud de batería.
